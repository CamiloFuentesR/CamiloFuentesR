## Hola, soy Camilo Fuentes

Desarrollador Full Stack y fundador de [AssistClass](https://assistclass.cl), en La Serena, Chile. Llevo más de cinco años desarrollando con JavaScript y TypeScript. Diseño, construyo y opero plataformas SaaS y sistemas de gestión a medida, desde el levantamiento de requerimientos hasta el despliegue y la operación en producción.

- Fundé y desarrollo AssistClass, una plataforma SaaS multi-tenant con más de 250 usuarios, de punta a punta: backend, frontend, base de datos e infraestructura.
- Construí un sistema de gestión offline-first que funciona sin señal en terreno y sincroniza al recuperar la conexión; a su cliente le redujo la administración diaria de 2 horas a 30 minutos.
- Participé en la migración del sistema Fondo Solidario de Agrosuper a React y TypeScript.
- Optimicé las consultas SQL de un sistema clínico: los informes se generan cerca de un 60 % más rápido.
